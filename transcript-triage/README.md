# Transcript Triage

Parse AI conversation transcripts into actionable topics.

## Quick Start

1. Save external AI chat as markdown
2. Trigger: `"triage transcript [file]"`
3. AI extracts numbered topics
4. You groom into NOW/LATER/BACKLOG
5. Items flow to ROADMAP, epic-notes, memory

## Why?

External AI chats generate insights but lack structure. This skill bridges conversations → actionable workflow.
